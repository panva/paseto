# Function: PublicKeyToCryptoKey()

> **PublicKeyToCryptoKey**(`key`): `CryptoKey`

Returns the native ECDSA P-384 public key retained by a built-in v3.public key.

## Parameters

| Parameter | Type | Description |
| :------ | :------ | :------ |
| `key` | [`PublicKey`](../interfaces/PublicKey.md) | Built-in v3.public key |

## Returns

`CryptoKey`
