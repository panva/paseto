# Variable: KDF\_ARGON2ID

> `const` **KDF\_ARGON2ID**: [`Argon2idFactory`](../type-aliases/Argon2idFactory.md)

Web Cryptography Argon2id implementation.

A custom [Argon2idFactory](../type-aliases/Argon2idFactory.md) can be used by third-party protocol implementations in runtimes
without Web Cryptography.
