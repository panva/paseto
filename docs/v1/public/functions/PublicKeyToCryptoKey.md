# Function: PublicKeyToCryptoKey()

> **PublicKeyToCryptoKey**(`key`): `CryptoKey`

Returns the native RSA-PSS public key retained by a built-in v1.public key.

## Parameters

| Parameter | Type | Description |
| :------ | :------ | :------ |
| `key` | [`PublicKey`](../interfaces/PublicKey.md) | Built-in v1.public key |

## Returns

`CryptoKey`
